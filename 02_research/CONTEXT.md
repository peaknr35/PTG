# 02_research: the evidence shelf

One job: hold the evidence PTG's rules rest on, graded honestly. **Factory / knowledge bundle.**

## Files
| File | Read it when | Contains |
|---|---|---|
| `library.md` | Looking up what's known on a topic | Graded evidence shelves (READ / SNIPPET / UNVERIFIED / NOT READ), and what each source does NOT justify |
| `resources.md` | Choosing a tool, dataset or reading | Tools (Kinovea, ffprobe, CVAT…), datasets, licenses, the update loop |
| `frameworks.md` | Designing a workflow | ICM+ : workflow papers checked against their abstracts, how to combine them |
| `papers/` | Only when a library card says to open the full text | PDFs sorted by topic (index below) |
| `clippings/` | A card cites a saved web article | Web articles saved as markdown |

## Load rules
- **Start at `library.md`.** Open a PDF only for a specific claim, and only the pages needed.
- Do NOT load a whole PDF into context. Do NOT load `06_books/` unless asked.

## How evidence gets added
New source → read the abstract → write a card in `library.md` (grade, finding, limits, "does NOT justify") → does it change a principle? → if yes, propose a revision to `01_foundation/foundation.md`.
