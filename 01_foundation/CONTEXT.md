One job: hold the stable rules, the shared vocabulary, and the reason PTG exists. **Factory.** Changes only by a reviewed revision (bump the version, add a date and a reason).

## Files
| File | Read it when | Contains |
|---|---|---|
| `foundation.md` | Writing or checking any claim, feature or output | KNOW/SEE/DO model · evidence grades A/B/C/P · principles P1–P15 · mentor-card output standard · feature admission test |

## Load rules
- Load **one** file for the task, not all three.
- Do NOT load: `02_research/` papers to "check" a principle. Go through `02_research/library.md` cards.

## Human check
Any change here: does it contradict another principle? Does every changed rule cite a library card? Is the version bumped?
