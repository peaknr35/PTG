# _templates: blank stamps to copy

One job: hold the stamps new work is copied from. **Never fill these in place.** Copy first. These are also the reusable method kit for client work.

| Template | Copy to | Use for |
|---|---|---|
| `rehearsal/` | `04_experiments/<run-name>/` | Any measurement rehearsal or session (README, predictions, capture checklist, event definitions, ledger, debrief) |
| `thinking-brief.md` | Next to the work it's about | Before any build brief: the problem, boundary, loops, delays, alternatives, smallest test, stop rule, prediction |
| `evidence-card.md` | Into `02_research/library.md` | One card per new source, including what it does NOT justify |

When a run improves a template (e.g., event definitions v1), update it here and note the version.
